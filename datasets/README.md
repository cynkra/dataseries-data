# Dataset datasheets

One markdown datasheet per catalog dataset (`<id>.md`). **These datasheets are the
source of truth.** Each one captures, in human- and AI-readable form, everything
needed to understand and re-fetch a dataset: where it comes from, the exact access
recipe (table id + query, or asset order number + sheet layout), what each
dimension means, the parsing quirks, and what is special or notable about it.

**The fetch/parse scripts in `R/` are a derivative of these datasheets.** Given a
datasheet, the corresponding fetcher (`source_*.R`) can be regenerated by an AI.
The institutional knowledge lives here, in prose, so it survives even if the code
rots or the source changes. When a source changes, update the datasheet first,
then regenerate the script from it.

**This includes display/presentation decisions, not just access + parsing.** Which
dimension becomes the multi-line breakdown, which dimensions are single-select, the
opening default view, and how seasonal adjustment is handled are all per-series
curation choices and belong here, in the `## Display` block. The catalog and app
DERIVE these from the datasheet (`read_datasheet_meta()` reads the `## Display`
fields into the dataset meta), instead of guessing them with code heuristics. Update
the datasheet, run `Rscript dev/rebuild_from_datasheets.R` (re-derives the meta
sidecars + `catalog.json` from disk, no refetch), and the app's behaviour follows.
The markdown is the one source of truth. (See [`../AGENTS.md`](../AGENTS.md) for the
full edit→regenerate workflow.)

## Template

```markdown
# <Human title>

- **id**: <ch_source_slug>
- **concept**: <Group / Leaf from ../docs/concepts.md>
- **canonical**: yes | no (alternate for <concept>)
- **featured**: <optional homepage label, e.g. "Inflation"; omit for non-featured>
  <only the handful of homepage example datasets carry this; drives the landing chips>

- **source**: <producer name>
- **license**: <snb | kof | fso | seco>  (terms)
- **frequency**: <monthly | quarterly | annual | daily>
- **coverage**: <start .. end>
- **series**: <n>
- **updated**: <source publish date>

## What is special
<Why this dataset matters; what is unusual, notable, or distinctive about it;
the quirks a user or a maintainer must know.>

## Access
- **type**: <SNB cube API | KOF API | SECO swissdata | FSO PX-Web | FSO DAM Excel>
- **endpoint / order number**: <...>
- **call**: <the exact fetch call>

## Parsing recipe
<Enough detail to regenerate the parser: sheet/endpoint, header rows, which
columns/dimensions are time vs dimension vs value, date encoding, number format,
reshape, rows to drop.>

## Dimensions
<each dimension column: what it means, key codes>

## Display
<presentation decisions the app derives from here>
- **split**: <the dimension that becomes the multi-line breakdown (multi-select)>
- **single-select**: <comma list of single-pick dimensions, e.g. type, seas_adj>
- **default**: <dim=code pairs for the opening view, e.g. structure=gdp, type=real, seas_adj=csa>
- **transform**: <level | yoy | index — the opening transform>
- **seasonal adjustment**: <how it is handled, e.g. single-select, default to the
  seasonally + calendar adjusted series (csa); raw (na) available as a toggle>

## Caveats / simplifications
<what was dropped, approximated, or is uncertain>

## Provenance
Script: `R/<file>::<function>`. Datasheet authored <date>; parser verified <date>.
```
